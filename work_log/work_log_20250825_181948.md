# Work Log - 2025/08/25 18:19:48

## Workspace Overview: soomac_ws

### 프로젝트 구조 분석

이 ROS 2 워크스페이스는 Soomac 로봇 제어를 위한 다양한 패키지들로 구성되어 있습니다.

### 주요 패키지

#### 1. dongsoo_cpp_pkg (C++ Package)
- **목적**: Dynamixel 모터 제어 및 중력보상 기능을 갖춘 실시간 로봇 제어
- **주요 파일**:
  - `src/motor_connect.cpp`: XH540-V270-R 모터 제어를 위한 핵심 노드
    - 5자유도 로봇팔 제어 (ID 1-5)
    - PID 제어 + 중력보상(피드포워드) 구현
    - JSON 기반 DH 파라미터 및 관성 정보 로드
    - BulkRead/SyncWrite를 통한 효율적인 모터 통신
  - `src/data_hub.cpp`: 데이터 허브 노드

#### 2. dongsoo_py_pkg (Python Package)
- **목적**: 상위 레벨 제어 알고리즘 및 데이터 처리
- **주요 노드**:
  - `data_hub.py`: 순기구학(Forward Kinematics) 계산 및 위치 데이터 처리
    - DH 변환 행렬 계산
    - 카메라/그리퍼 위치 계산
    - JSON 기반 설정 로드 (안전한 표현식 파싱)
  - `trajectory_test.py`: 궤적 계획 및 테스트
  - `one_way_trajectory.py`: 일방향 궤적 제어
  - `motor_dummy.py`: 모터 시뮬레이터/더미 노드
- **Entry Points**: trajectory_test, one_way_trajectory, motor_dummy, data_hub_py

#### 3. dongsoo_description (Description Package)
- **목적**: 로봇 기구학 파라미터 및 설정 정보 저장
- **주요 설정 파일**:
  - `base_to_gripper_dh.json`: 그리퍼까지의 DH 파라미터 (5자유도)
  - `base_to_camera_dh.json`: 카메라까지의 DH 파라미터
  - `gravity_dh_param.json`: 중력보상을 위한 DH 파라미터
  - `link_inertial.json`: 링크별 질량 및 관성 정보

#### 4. finger_test (Python Package)
- **목적**: 손가락/그리퍼 제어 테스트
- **파일**: `finger_test.py`

#### ROS 2 Topic 구조
```
/motor/position         (Int32MultiArray)    - 현재 모터 위치
/motor/current          (Float32MultiArray)  - 현재 모터 전류
/motor/velocity         (Float32MultiArray)  - 현재 모터 속도
/motor/command_position (Int32MultiArray)    - 목표 위치 명령 (1-4번 모터)
/motor/command_dxl5_position (Int32MultiArray) - 5번 모터 별도 명령
/datahub/grip_pose      (Float32MultiArray)  - 그리퍼 위치 (x,y,z)
/datahub/cam_pose       (Float32MultiArray)  - 카메라 위치 (x,y,z)
```
