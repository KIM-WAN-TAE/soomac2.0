## 기술적 세부사항

### JSON 구조 차이점 해결
- **기존 파일들**: `dh_parameters` → `joints` → 직접 파라미터
- **gravity_dh_param.json**: `gravity_dh_parameters` → `joints` → `dh_params` → 파라미터
- 구조적 차이로 인해 별도 GravityDH 클래스 필요성 확인

### IK 정확도 문제 분석
#### "정확도 부족" 오류 의미
- 위치 + 방향 오차의 총합이 설정된 임계값 초과 시 발생
- 초기 설정: `np.linalg.norm(res.fun) > 0.01` (1cm)
- **원인**: 
  - Singularity 근처에서의 수치적 불안정성
  - 로봇 작업공간 경계 근처 목표점
  - 복잡한 orientation 제약 조건

#### 해결 방안 (최종 버전에서 적용)
1. **단계별 IK 접근법**:
   - 시작점: 위치만 제약 (orientation 자유)
   - 끝점: 위치 + orientation 제약
2. **적응적 가중치 감소**: orientation 가중치를 재시도할 때마다 감소 (w *= 0.6)
3. **폴백 메커니즘**: orientation 제약 실패 시 위치만 만족하는 해 수용
4. **관절공간 보간**: P2P IK 후 관절각도 직접 보간으로 안정성 확보
